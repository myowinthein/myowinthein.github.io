# myowinthein.github.io

Personal landing page for [Myo Win Thein](https://github.com/myowinthein), listing public repositories owned by the user.

## Install

No install required. Clone and open `index.html` in a browser.

```sh
git clone https://github.com/myowinthein/myowinthein.github.io.git
cd myowinthein.github.io
open index.html   # macOS; use xdg-open on Linux or just double-click
```

## Usage

The page fetches all of the owner's public GitHub repos at runtime, following pagination and sorting by most recently updated. Forks and this site's own repository (`myowinthein.github.io`) are excluded. GitHub Pages and a homepage URL are optional: cards link to a valid HTTP(S) homepage when available, otherwise to the GitHub repository. No build step, no server needed.

To deploy changes, push to `main`; GitHub Pages publishes automatically.
