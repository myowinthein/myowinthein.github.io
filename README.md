# myowinthein.github.io

My GitHub Pages landing page, with my profile and public projects.

[Visit the site](https://myowinthein.github.io).

## Why I built this

I hadn't planned to build this page. After I started using GitHub Pages for my
other projects, I noticed that the parent address, `myowinthein.github.io`, had
no page of its own.

So I created this repository as a simple place to share my profile and projects.
GitHub supplies the content, so I can keep it current by updating my profile and
repositories without maintaining a separate project list.

## What's included

The page loads my name, bio, location, website and social links from GitHub.
It lists my public repositories, excluding forks and this repository, with the
most recently updated first. Each project links to its source and, when
available, its own website.

It also includes light and dark themes, a responsive layout and a **Load more**
button for browsing additional projects.

I built it with plain HTML, CSS and JavaScript to keep it simple. No framework,
package manager or build step.
