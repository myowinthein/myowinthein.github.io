# myowinthein.github.io

My GitHub Pages landing page, with my profile and public projects.

[Visit the site](https://myowinthein.github.io)

## About this site

My profile and public projects, loaded from GitHub. The page includes my profile
image, bio, company, location, website and social links when available.

Projects appear with the most recently updated first, excluding forks and this
repository. Cards show descriptions, latest release versions and archived
status when available. Each links to its source and, when available, its website
and license file.

Built with plain HTML, CSS and JavaScript, without a framework or build step.

## Contributing

This is a personal site. Issues and PRs are not expected.
